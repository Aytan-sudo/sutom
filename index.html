    Règles
    
    
    Devinez le mot en six essais. Sa longueur change à chaque partie. La première lettre est offerte : elle est déjà inscrite dans la grille, tapez seulement la suite du mot.
    
    
      
        
    • A lettre bien placée
      • 
        
    • B lettre présente ailleurs dans le mot
      • 
        
    • C lettre absente du mot
      • 
    
    
    
    Les lettres bien placées restent affichées dans les essais suivants ; une option permet de les effacer pour sacrifier un essai et tester d'autres lettres. Les accents ne comptent pas : tapez ete pour été.
    
    
    La touche Vide (ou la barre d'espace) saute une case : de quoi écrire la fin d'un mot pour le voir en place. Un essai ne part que si toutes les cases portent une lettre.
    
    
    Le mot du jour
    
    
    Le bouton ☀ propose le mot du jour : le même pour tout le monde, trouvé par chaque navigateur à partir de la date, sans serveur. Le réussir chaque jour allonge une série, visible dans les statistiques. Un lien de défi rouvert plus tard redonne la grille, mais reste hors série.
    
    
    Le passeport
    
    
    Ouvert depuis le hub avec un passeport, le jeu garde les statistiques et les réglages du joueur. Trouver un mot donne le tampon Mots, même au premier essai. Sinon, dix mots essayés dans la journée, sur une ou plusieurs parties, le donnent aussi : les mots faux comptent, pas ceux que le dictionnaire refuse.
    
    
    Au clavier
    
    
    Les lettres et Retour arrière écrivent, Entrée valide (et relance une partie une fois celle-ci finie), la barre d'espace saute une case, Échap ferme un dialogue. Les 26 lettres appartenant à la grille, la palette et les autres réglages n'ont pas de raccourci : ils passent par les boutons de l'en-tête.
    
    
    Mots issus de Lexique 3.83.
